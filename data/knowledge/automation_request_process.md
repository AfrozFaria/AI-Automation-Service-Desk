# Requesting an Automation
## Step 1: Submit an idea
Describe the process, how often it runs and how long each case takes using the Automation Request form.
## Step 2: Assessment
The AI Support Desk scores each request for impact and feasibility within 5 working days.
## Step 3: Workshop
High-priority requests get a 60-minute workshop with the business owner and a developer.
## Step 4: Build and pilot
Solutions are built iteratively and piloted for 4 weeks with a human reviewing all outputs.
## Step 5: Maintenance
Each automation has an owner and is reviewed every quarter.
